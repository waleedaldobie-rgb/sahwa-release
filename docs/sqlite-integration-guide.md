# دليل ربط Electron بقاعدة بيانات SQLite المحسنة - نظام صهوة

يعتمد نظام **صهوة** على معمارية متعددة الطبقات لضمان فصل المهام واستقرار البيانات. فيما يلي الخطوات التقنية التي تم تنفيذها لربط واجهة React بقاعدة بيانات SQLite الحقيقية داخل بيئة Electron.

## 1. الهيكلية العامة للربط (Layered Architecture)

يتم الربط عبر سلسلة من الطبقات المتصلة:
> **React UI** (الواجهة) → **Preload API** (الجسر) → **IPC Handlers** (المستقبل) → **Services** (المنطق) → **Repositories** (البيانات) → **SQLite DB** (التخزين)

## 2. خطوات التنفيذ التقني

### أولاً: إدارة مسار البيانات (Persistence Strategy)
يتم تخزين قاعدة البيانات في مجلد بيانات المستخدم الخاص بالنظام (`userData`) لضمان عدم فقدان البيانات عند تحديث التطبيق.
- **المسار في Windows:** `%APPDATA%/sahoa/database/sahwa.db`
- **الكود المسؤول:** استخدام `app.getPath('userData')` في `main.ts`.

### ثانياً: تهيئة مدير قاعدة البيانات (`SahwaDatabaseManager`)
يتم استدعاء المدير عند بدء تشغيل التطبيق ليقوم بالمهام التالية:
1. التأكد من وجود المجلدات اللازمة (database, backups).
2. فتح الاتصال باستخدام مكتبة `better-sqlite3`.
3. تنفيذ الـ **Migrations** (التحويلات) لتحديث هيكل الجداول تلقائياً.

### ثالثاً: تسجيل معالجات IPC
في ملف `src/electron/ipcHandlers.ts` يتم ربط كل قناة IPC بالخدمة المناسبة:
```typescript
// مثال لربط جلب موديلات الثياب
safeIpcHandle(ipcMain, 'thobeTypes:list', async () => thobeTypeRepository.list());
```

### رابعاً: جسر التوصيل (`preload.ts`)
يتم تعريض الدوال للواجهة الأمامية بشكل آمن دون السماح للواجهة بالوصول المباشر لـ Node.js:
```typescript
// في preload.ts
getThobeTypes: () => ipcRenderer.invoke('thobeTypes:list'),
```

## 3. جدول ملخص المكونات الأساسية

| المكون | الملف المسؤول | الوظيفة |
|---|---|---|
| **قاعدة البيانات** | `src/electron/db.ts` | إدارة الاتصال، النسخ الاحتياطي، والتهيئة. |
| **الهيكل والجداول** | `src/electron/schema.ts` | تعريف جداول SQLite (الطلبات، المخزون، الصندوق). |
| **التحديثات التلقائية** | `src/electron/migrations.ts` | ترقية قاعدة البيانات عند إضافة ميزات جديدة. |
| **المستودعات** | `src/electron/repositories/` | تنفيذ استعلامات SQL المتخصصة (Insert, Update, Delete). |

## 4. كيفية التحقق من الربط
عند تشغيل النسخة المثبتة، يمكنك التأكد من عمل الربط من خلال:
1. **السجل (Logs):** فحص ملفات السجل للتأكد من نجاح `dbManager.initDatabase()`.
2. **العمليات:** إضافة صنف جديد في المخزون وإغلاق التطبيق ثم فتحه؛ إذا بقي الصنف موجوداً، فالربط بـ SQLite يعمل بنجاح.
3. **الأداء:** سرعة الاستجابة في التقارير المالية تدل على استخدام الفهارس (Indexes) المحسنة في SQLite.

---
**ملاحظة:** تم ضبط نظام التغليف (Electron Builder) ليقوم بعمل Rebuild لمكتبة `better-sqlite3` لتتوافق مع معمارية Windows المستهدفة (x64) تلقائياً أثناء البناء.
